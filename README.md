# Global Warming Forecasting Tool – A Data-Driven Approach to Climate Prediction

## Project Overview

Global Warming Forecasting Tool is a climate analytics and forecasting application developed using Python and Streamlit. The project analyzes historical climate datasets, identifies long-term environmental trends, and predicts future climate patterns using statistical forecasting techniques.

The objective of this project is to provide an interactive platform for climate trend analysis and future forecasting while supporting data-driven environmental decision-making. The project aligns with United Nations Sustainable Development Goal (SDG) 13: Climate Action.

This project was developed as a Minor Project and serves as the foundation for a future Major Project with enhanced forecasting capabilities, advanced machine learning integration, and real-time climate data analysis.

---

## Problem Statement

Global warming is one of the most significant environmental challenges faced by the world today. Rising greenhouse gas concentrations, increasing global temperatures, and changing climate patterns have serious environmental, economic, and social impacts.

Many existing forecasting systems are either complex, region-specific, or lack interactive visualization capabilities. This project aims to provide an accessible climate forecasting platform that analyzes historical climate data, predicts future trends, and presents insights through interactive visualizations.

## Evaluation Metrics

### Mean Absolute Error (MAE)
Measures the average difference between actual and predicted values.

### Root Mean Square Error (RMSE)
Measures forecasting accuracy while giving higher importance to larger prediction errors.
